# 📊 Superstore Sales Dashboard

An interactive **Excel Data Analytics Dashboard** created to analyze Superstore sales performance, profitability, customer segments, regions, categories, and yearly trends.

## 📌 Project Overview

This project uses the **Superstore dataset** to explore sales and profit performance from **2014 to 2017**.

The dashboard was created using **Microsoft Excel**, with Pivot Tables and interactive visualizations to transform raw sales data into meaningful business insights.

## 🎯 Project Objectives

The main objectives of this project are:

* Analyze overall **Sales, Profit, and Quantity**
* Understand sales performance across different **Regions**
* Compare different **Product Categories**
* Analyze customer **Segments**
* Identify sales trends over the years
* Analyze product **Sub-Categories**
* Compare different **Shipping Modes**
* Identify areas with strong and weak profitability
* Present the analysis through an interactive dashboard

## 📊 Dashboard Analysis

The dashboard provides analysis of:

### 🌎 Regional Performance

Sales are analyzed across:

* West
* East
* Central
* South

The **West region** has the highest sales among the four regions.

### 🛍️ Category Analysis

The three main product categories are:

* Technology
* Furniture
* Office Supplies

**Technology** generates the highest sales among the three categories.

### 👥 Customer Segment Analysis

The dashboard analyzes:

* Consumer
* Corporate
* Home Office

The **Consumer segment** contributes the largest share of sales.

### 📦 Sub-Category Analysis

The project analyzes sales and profitability across multiple sub-categories, including:

* Phones
* Chairs
* Storage
* Tables
* Binders
* Machines
* Accessories
* Copiers
* Bookcases
* Appliances

### 🚚 Shipping Mode Analysis

The dataset contains four shipping modes:

* Standard Class
* Second Class
* First Class
* Same Day

**Standard Class** accounts for the highest sales.

### 📅 Yearly Sales Trend

The dashboard also analyzes sales performance across the four years:

**2014 → 2015 → 2016 → 2017**

This helps identify changes and growth in sales over time.
